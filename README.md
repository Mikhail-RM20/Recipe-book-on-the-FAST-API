Простое FastAPI‑приложение для управления рецептами.
Реализованы основные операции: создание рецепта, просмотр всех рецептов и просмотр рецепта по ID.

---

## Функционал API

### 1. Создание рецепта

- Эндпоинт:
  `POST /recipes`
- Принимает данные о рецепте и его ингредиентах в формате Pydantic‑схемы.
- Проверяет, что рецепт с таким именем уже не существует в базе данных.
- Добавляет новый рецепт и связанные с ним ингредиенты в базу.

### 2. Просмотр всех рецептов

- Эндпоинт:
  `GET /recipes`
- Возвращает список всех рецептов.
- Для каждого рецепта возвращаются:
    - название,
    - время приготовления,
    - количество просмотров,
    - список ингредиентов с их количествами.

### 3. Просмотр рецепта по ID

- Эндпоинт:
  `GET /recipes/{recipe_id}`
- Принимает `recipe_id` — числовой идентификатор рецепта.
- Возвращает полную информацию о рецепте по его ID (если он существует).

## Запуск приложения

Проект находится в директории `homework`.

1. Перейдите в корень проекта:
   ```bash
   cd ~/PycharmProjects/python_advanced/module_26_fastapi/homework
   ```

2. Запустите приложение с помощью `uvicorn`:
   ```bash
   uvicorn src.main:app --reload
   ```

После запуска API будет доступно локально по адресу:
`http://127.0.0.1:8000`
